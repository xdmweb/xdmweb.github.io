## Install XDM on Windows in three steps

<ol class="steps-list">
  <li><strong>Run the MSI</strong> you just downloaded and accept the administrator prompt.</li>
  <li><strong>If SmartScreen appears</strong>, click <span class="ui">More info</span> → <span class="ui">Run anyway</span>.
      XDM is open source without a paid signing certificate, so Windows doesn't recognise it yet.</li>
  <li><strong>Start XDM</strong> and install the <a href="/extension/">browser extension</a> from the setup window.</li>
</ol>

More detail, per-user installs and uninstalling: [Install XDM on Windows](/guide/install-windows/).


## Which file do I need?

| Your PC | Choose |
|---|---|
| Most laptops and desktops (Intel Core, AMD Ryzen) | **64-bit (x64)** |
| Snapdragon / Copilot+ PCs, Surface Pro X, other Windows on ARM devices | **ARM64** |
| Prefer automatic updates | XDM 8 from the **Microsoft Store** |
| Still on Windows 7 | XDM 8's Windows 7 installer (unsupported, no security updates) |

Not sure? Open **Settings → System → About** and look at *System type*: “x64-based processor” means x64,
“ARM-based processor” means ARM64.

## Is it safe?

XDM is free, open-source software. The installers contain no adware, toolbars or bundled offers, and they're
built from the public source code on GitHub. Download XDM only from this site or the official GitHub releases.
Copies on third-party download portals may be repackaged.
