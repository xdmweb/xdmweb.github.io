## Install XDM while it downloads

<ol class="steps-list">
  <li><strong>Open the file</strong> when the download finishes: click it in your browser's download list, or
      find it in your <em>Downloads</em> folder.</li>
  <li><strong>Allow the installer.</strong> Windows asks for administrator permission. If SmartScreen says
      <em>“Windows protected your PC”</em>, click <span class="ui">More info</span> → <span class="ui">Run anyway</span>.</li>
  <li><strong>Start XDM</strong> from the Start menu. The <em>Set up browser integration</em> window opens.</li>
</ol>

## Get the most out of XDM

- **Faster downloads**: XDM splits files into segments automatically. Tune it in
  [Speed up downloads](/guide/speed-up-downloads/).
- **Save videos**: play a video and click the XDM icon in your browser. See
  [Download videos](/guide/download-streaming-video/).
- **Resume anything**: if a link expires, [Refresh link](/guide/refresh-link/) continues where it stopped.
- **Download overnight**: [schedule downloads](/guide/schedule-downloads/) and let XDM shut down the PC when done.


## Trouble installing?

- **The installer won't open**: right-click the file → *Properties* → tick *Unblock* → OK, then try again.
- **“Another version is installed”**: uninstall a Microsoft Store copy of XDM 8 first. See
  [Update &amp; migrate](/guide/update-and-migrate/).
- **Antivirus removed the file**: see [antivirus and firewall](/help/antivirus-and-firewall/).
- Everything else: the [help center](/help/).
