How to tell which processor you have

  • Windows: Settings → System → About → System type. “x64-based” means x64, “ARM-based” means ARM64.
  • Mac: → About This Mac. “Chip: Apple M…” means Apple silicon; “Processor: Intel” means Intel.
  • Linux: run uname -m. x86_64 means x86-64, aarch64 means ARM64.

Safe, clean and free

XDM is open-source software, built in public on GitHub. The installers don't bundle toolbars, adware or “special offers”, and XDM never shows ads inside the app. Because XDM isn't signed with a paid commercial certificate, Windows SmartScreen and macOS Gatekeeper ask you to confirm the first launch. The install guides show exactly what to click.

Lightweight, too. XDM is a native app, not an Electron or webview wrapper, so it doesn't run a hidden browser engine in the background. XDM 9 idles at about 30 MB of memory on Windows, leaving your computer free for actual work.

Download XDM only from this site or the official GitHub releases. Copies on third-party download portals can be repackaged with unwanted software.

Download questions

Is XDM really free?

Yes. There's no paid edition, trial or feature limit. The website is supported by ads.

Do I need Java?

No. Every installer includes the runtime XDM needs.

Can I keep XDM 8 and install XDM 9?

No. Both use the same browser connection, so XDM 9's installer replaces XDM 8. See Update & migrate.

Where are older versions?

In the version archive. Older versions are unsupported and may not work with current browsers.
