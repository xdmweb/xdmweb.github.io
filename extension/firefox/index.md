## Firefox tips

- **Site access**: Firefox may install the add-on with access limited to some sites. Open `about:addons` →
  *XDM* → *Permissions* and allow access to all websites.
- **Private windows**: on the add-on's page, set *Run in Private Windows* to *Allow* if you want XDM there.
- **Firefox ESR and forks** (LibreWolf, Waterfox, Floorp) can usually install the add-on from the same page.
