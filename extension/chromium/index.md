## Browser-specific notes

| Browser | How |
|---|---|
| **Opera / Opera GX** | Install Opera's *Install Chrome Extensions* add-on first, then use the Chrome Web Store button. |
| **Vivaldi** | Works directly: open the store and click *Add to Chrome*. |
| **Chromium** (Linux) | Works directly from the Chrome Web Store. |
| **Yandex, Arc, Thorium and others** | Usually work directly. If the store refuses, check the browser's extension settings. |

Safari isn't supported. On a Mac, use XDM with Chrome, Edge, Firefox or Brave.
