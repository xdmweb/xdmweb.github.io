
## What the extension does

- **Takes over downloads**: when the browser starts a download of a supported file type (archives,
  installers, disk images, documents, audio and video), XDM downloads it instead, faster and resumable.
- **Finds videos** while you watch them. The XDM icon shows how many it found. Pick a quality and XDM saves it.
  See [Download videos](/guide/download-streaming-video/).
- **Right-click options**: *Download with XDM*, *Download Image with XDM*, *Download all with XDM…* and
  *Download selected links with XDM…*.

## Permissions and privacy

The extension needs access to the sites you download from, so it can see downloads and the cookies a site
requires. Everything it reads goes to **one place only: the XDM app on your own computer**
(`127.0.0.1`). It has no server, no analytics and no tracking, and it stays off YouTube completely.
Read the [privacy policy](/privacy.html).

## Not working?

| You see | Do this |
|---|---|
| **XDM isn't running** in the popup | Start XDM (or click *Launch XDM* in the popup). |
| **Site access is restricted** | Click *Allow on all sites* in the popup. |
| Downloads still go to the browser | Check the file type in XDM → Settings → Browser. See [browser not capturing](/help/browser-not-capturing/). |
| No videos detected | Play the video for a few seconds. See [video not detected](/help/video-not-detected/). |
| Can't connect at all | See [extension can't connect](/help/extension-cannot-connect/). |

Don't have XDM yet? [Download it here](/download/). The extension needs the app.
